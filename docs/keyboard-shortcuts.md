# Atajos de teclado

Los atajos no se activan mientras se escribe en un campo de texto ni con un
diálogo abierto. La misma tabla aparece en Ayuda dentro de la aplicación.

| Teclas | Acción |
| ------ | ------ |
| `P` `E` `L` `R` `C` `F` `T` `S` | Lápiz, borrador, línea, rectángulo, elipse, relleno, texto, selección |
| `Ctrl+Z` / `Ctrl+Y` (o `Ctrl+Mayús+Z`) | Deshacer / rehacer |
| `Ctrl+S` | Guardar (web: descargar copia) |
| `Ctrl+Mayús+S` | Guardar como (escritorio) |
| `Ctrl+O` | Abrir proyecto |
| `Ctrl+Alt+N` | Nuevo proyecto |
| `Ctrl+A` | Seleccionar todo |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Copiar, cortar, pegar la selección (sin contenido interno, `Ctrl+V` pega una imagen) |
| `Supr` / `Retroceso` | Borrar la selección |
| `Esc` | Quitar la selección o cancelar la vista previa de imagen |
| `,` / `.` | Fotograma anterior / siguiente |
| `Espacio` | Reproducir / detener |
| `O` | Papel cebolla |
| Flechas | Mover la selección; sin selección, desplazar el dibujo |
| Clic derecho | Dibujar apagando píxeles |
| `Mayús` al dibujar | Líneas a 0°/45°/90° y rectángulos/elipses proporcionales |
| `Ctrl` al arrastrar la selección | Copiar en lugar de mover |

## En el lienzo (con el foco en él)

| Teclas | Acción |
| ------ | ------ |
| Flechas | Mover el cursor de píxel |
| `Mayús` + flechas | Mover el cursor 5 (LCD de caracteres) u 8 píxeles |
| `Espacio` / `Intro` | Cambiar el píxel bajo el cursor |
| `Supr` / `Retroceso` | Apagar el píxel bajo el cursor |
| `Esc` | Ocultar el cursor |

## Línea de tiempo (con el foco en un fotograma)

| Teclas | Acción |
| ------ | ------ |
| `←` / `→`, `Inicio`, `Fin` | Seleccionar fotograma |
| `Alt+←` / `Alt+→` | Mover el fotograma seleccionado |

## Paneles

En la barra de pestañas: `←`/`→`, `Inicio` y `Fin`. En la caja de
herramientas: flechas para cambiar de herramienta.
